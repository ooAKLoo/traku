# Raku 产品说明文档

## 产品概述

Raku 是一款智能语音记录与灵感管理应用，通过 AI 技术将用户的随想、灵感和思考转化为结构化的知识资产。产品核心理念是"捕捉瞬间灵感，构建个人知识体系"。

## 核心价值主张

1. **即时捕捉**：支持手机录音和外置设备录音，随时随地记录灵感
2. **智能处理**：AI 自动转录、润色、总结和标签化，将碎片化语音转为结构化内容
3. **高效管理**：通过标签系统和空间功能，构建个人化的知识管理体系
4. **灵活导出**：支持多种格式导出，方便二次创作和分享

## 主要功能模块

### 一、首页 - 录音列表管理

#### 1.1 核心功能
- **录音卡片展示**：以天气主题的卡片形式展示所有录音
- **双维度筛选**：支持"标签"和"空间"两种组织维度切换
- **智能搜索**：AI 驱动的语义搜索，支持模糊查询
- **实时状态**：显示录音处理进度（转录中、优化中、完成）

#### 1.2 交互设计
- **左滑删除**：圆形进度指示器提供视觉反馈
- **点击进入详情**：查看和编辑录音内容
- **悬浮录音按钮**：快速开始新录音
- **空状态引导**：无内容时的友好提示

#### 1.3 视觉特色
- **天气主题**：每条录音根据录制时的天气显示不同图标和配色
- **流光动画**：搜索时的动态光效增强科技感
- **深浅模式**：完整的主题切换支持

### 二、详情页 - 内容查看与编辑

#### 2.1 内容展示
- **基础信息**：可编辑标题、时间戳、标签组
- **双版本转录**：原始转录和 AI 润色版本，滑动切换
- **AI 增强内容**：
  - 对于"思考"类录音：生成结构化的 Markdown 内容，包含大纲、要点等
  - 对于"灵感"类录音：展示相似灵感推荐

#### 2.2 编辑功能
- **标题编辑**：点击即可修改，自动保存
- **转录编辑**：支持编辑原始和润色版本
- **章节编辑**：AI 内容的每个章节可独立编辑、复制或删除
- **标签管理**：添加、删除标签，支持创建新标签

#### 2.3 导航与操作
- **顶部导航栏**：返回、播放/暂停、下载音频、更多选项
- **章节导航**：底部悬浮标签栏，快速跳转到不同章节
- **分享导出**：
  - 分享为文本（包含标题、转录、总结）
  - 导出音频文件（WAV 格式）
  - 复制摘要到剪贴板

### 三、空间 - 灵感项目管理

#### 3.1 空间概念
空间是主题化的容器，用于组织相关的录音和想法，类似于项目文件夹但更智能。

#### 3.2 核心功能
- **模板化创建**：9 种预设模板快速开始
  - 产品灵感库
  - 设计灵感
  - 商业想法
  - 学习笔记
  - 创作灵感
  - 个人感悟
  - 运营策划
  - 用户反馈
  - 会议任务

- **灵感池**：
  - 所有未分类的录音集中管理
  - 筛选：全部/已使用/未使用
  - 批量添加到空间

- **空间内管理**：
  - 分类标签页组织内容
  - 时间轴展示
  - 标记重要条目
  - 支持手动添加文本

#### 3.3 交互特色
- **网格布局**：空间卡片视觉化展示
- **滑动手势**：标记重要或删除
- **内联编辑**：点击即可编辑内容
- **批量操作**：多选模式高效管理

## 技术亮点

### AI 能力
1. **语音识别**：基于火山引擎的高准确度 ASR
2. **内容优化**：LLM 驱动的润色和结构化
3. **智能标签**：自动提取关键词和分类
4. **语义搜索**：基于向量的相似度匹配

### 用户体验
1. **原生 SwiftUI**：流畅的动画和手势
2. **实时同步**：多视图间的数据一致性
3. **离线优先**：本地数据库确保可用性
4. **隐私保护**：数据本地存储，可选云同步

## 目标用户画像

1. **产品经理**：记录用户反馈、产品想法、竞品分析
2. **设计师**：捕捉设计灵感、交互创意、视觉参考
3. **创业者**：商业构想、市场洞察、战略思考
4. **知识工作者**：学习笔记、研究想法、知识整理
5. **创作者**：写作素材、创意片段、内容规划

## 产品差异化

1. **极简录音**：降低记录门槛，随时捕捉想法
2. **AI 赋能**：不只是录音工具，更是智能助手
3. **灵活组织**：标签+空间双维度满足不同场景
4. **优雅设计**：天气主题和动效提升使用愉悦感

## 商业模式建议

1. **免费版**：基础录音、转录、标签功能
2. **高级版**：
   - 无限 AI 优化次数
   - 高级导出格式
   - 云端同步
   - 团队协作空间
3. **企业版**：私有部署、API 接入、定制化功能

## 未来发展方向

1. **协作功能**：团队共享空间、评论互动
2. **知识图谱**：可视化灵感关联网络
3. **智能提醒**：基于内容的行动建议
4. **多模态输入**：图片、手写等更多输入方式

Raku 通过将 AI 技术与优雅的产品设计结合，为用户提供了一个强大yet简单的个人知识管理工具，真正实现了"让每一个想法都有价值"的产品愿景。
